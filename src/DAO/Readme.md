# University Student Management System

## Project Description
A Java-based application designed to manage university students,
courses, instructors, and student enrollments using PostgreSQL.

## Technologies Used
- Java
- PostgreSQL
- JDBC
- IntelliJ IDEA
- Git and GitHub

## Features
- Student management
- Course management
- Instructor management
- Student enrollment
- Database connectivity
- CRUD operations

## Project Structure
- APP: Main application
- LAB1: Classes and inheritance
- LAB2: Database connection
- DAO: Database operations

## Database
Database name: university
